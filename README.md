# 负载曲线生成工具

四个 notebook 分别沿用累计电量差分、功率按小时取均值、订单按时长分配和电费单分时均摊的方法。选择对应 notebook，在首个代码单元修改路径和配置。

## 开始使用

在本目录运行（推荐 Python 3.11 或 3.12）。

```sh
python -m pip install -r requirements.txt
jupyter lab
```

新建本地 `inputs/`，放入电价表和对应的原始数据。默认从 Excel 的第一个工作表读取，电价表须覆盖 12 个月 × 24 小时，列名为 `月份`、`小时`、`电价类型`、`电价`。月份用 1–12，小时用 0–23，时段用尖、峰、平、谷，电价单位为元/kWh。运行所选 notebook 的全部单元，结果写入 `outputs/`。

| 文件 | 输入要求与配置 |
| --- | --- |
| 01_cumulative_meter.ipynb | 单只表每天一行，日期列加 00:00 到 23:45 的 96 列，列标题可使用 H:MM 或 HH:MM。为完整计算 12 月 31 日最后一小时，需有次年首日 00:00 累计读数。改日期列名、工作表和倍率。 |
| 02_power_readings.ipynb | 每行一个规律采样时间戳和总有功功率（kW）。改读取列、表头位置及倍率，有多个测量点时先配置点号筛选。 |
| 03_charging_orders.ipynb | 每行一笔订单，提供开始、结束时间和 kWh。预先确认时间是本地时间，全年订单已覆盖，并处理重复、冲正和异常订单。跨年订单按落在目标年内的时长参与汇总。 |
| 04_monthly_bills.ipynb | 把 PDF 或其他账单预先汇总成 12 行 Excel，列为月份、尖、峰、平、谷，单位 kWh。无该时段填 0。 |

## 输出与复核

主表为 8760 行，目标年须为非闰年。列顺序为日期、小时、月份、电价类型、电价、负载、负载来源。表计方案先按真实时间戳聚合，再补缺失小时，校核表按月份和来源汇总。电表源不足整年时，应先按项目口径完成跨年拼接或典型月扩展，再核对补值比例和月度电量。订单校核表验证目标年内电量守恒。电费单校核表逐月逐时段核对电量，均摊曲线无法反映真实峰值需量。
